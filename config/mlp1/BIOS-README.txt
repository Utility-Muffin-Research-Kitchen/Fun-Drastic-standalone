Fun DraStic includes DraStic's own free replacement BIOS, so most games run
with no setup at all.

Some games refuse to start without the original Nintendo DS BIOS, and the DS
firmware settings (username, birthday, favourite colour, system language) need
the firmware dump. Those files are not included. Source them from hardware you
own and place them in BIOS/NDS on your SD card using these filenames:

  nds_bios_arm7.bin    16 KB
  nds_bios_arm9.bin     4 KB
  nds_firmware.bin

Leaf copies whichever of them it finds into Fun DraStic's private runtime
system directory when the emulator starts. Do not place them in the
release-managed emulator folder because an update may replace it.
